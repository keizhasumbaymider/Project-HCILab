# Project HCILab

A Human-Computer Interaction (HCI) project developed as part of a university coursework project.

The project focuses on designing and developing a web-based interface with an emphasis on **user experience, usability, visual design, and interaction**.

## Overview

This project was created to apply HCI concepts throughout the design and development process, including interface design, interaction design, and implementation.

The design was initially developed in **Figma** and then implemented into a functional web interface using HTML, CSS, and JavaScript.

## Features

* Responsive web interface
* Interactive navigation and UI components
* Event and content sections
* Tenant directory
* Tenant detail modal
* Interactive carousel
* Scroll-based navigation effects
* Responsive layout and visual design

## Design Process

The project applies several HCI and UI/UX principles throughout the development process:

1. **User & Problem Understanding**

   * Identifying user needs and requirements.
   * Considering usability and accessibility in the interface.

2. **Interface Design**

   * Creating wireframes and visual designs in Figma.
   * Establishing layout, typography, colors, and visual hierarchy.

3. **Prototyping**

   * Developing interactive prototypes to explore user interactions and navigation.

4. **Implementation**

   * Translating the design into a functional web interface using HTML, CSS, and JavaScript.

5. **Evaluation & Refinement**

   * Reviewing the interface and refining visual and interaction elements based on the project requirements.
